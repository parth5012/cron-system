Slide 2 — The TDD Trap

Headline: Why AI Agents Fail at Testing

When agents generate code and tests together, they introduce confirmation bias: writing tests structurally incapable of failing. Enforce Red-Green-Refactor with the TDD skill: failing tests first, real implementation second, 80%+ coverage verification.

Slide 3 — Pre-Execution Interrogation

Headline: Grill With Docs

Junior engineers rush to write code. Senior engineers read ADRs and domain models first. The grill-with-docs skill maps existing plugins and interrogates your architectural choices before touching any files.

Slide 4 — Security-Grade PR Review

Headline: Automated Senior Code Review

Beyond linter checks: analyzing security-critical changes in auth middleware. Flagging CSRF bypasses, unconstrained string invariants, and missing staging audit logs before you merge.

Slide 5 — The Compounding Asset

Headline: Build Skills That Build Skills

Models get swapped every few months. Reusable engineering skills remain permanent. Package your team's best habits into SKILL.md workflows. Your harness is your competitive edge.
