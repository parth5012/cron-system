System Design Study Plan

HLD (distributed systems, scalability, databases, messaging, availability) + LLD (OOP, SOLID, patterns, schema, concurrency, machine coding). ~8-10 hrs/week. Depth > speed.

Phase 0 — Foundations (Week 1)

  • OSI model, TCP vs UDP, HTTP/1.1 vs HTTP/2 vs HTTP/3, gRPC, WebSockets (Hussein Nasser)
  • DNS, CDN, load balancers (L4 vs L7), reverse proxies, connection pooling (HN)
  • SQL vs NoSQL, B-trees, LSM trees, indexing, ACID, isolation levels (HN + DDIA ch.1-4)
  • Read System Design Primer "System Design Topics" + "Trade-offs" cheat sheets

Deliverable: 1-page cheat sheet of trade-offs (latency vs throughput, consistency vs availability)

Phase 1 — HLD Building Blocks (Weeks 2-3)

  • Caching: cache-aside, write-through, write-back, write-around; eviction (LRU/LFU); thundering herd (Gaurav Sen + ByteByteGo)
  • Replication: single-leader, multi-leader, leaderless; sync vs async; read replicas (DDIA ch.5)
  • Partitioning/sharding: hash, range, consistent hashing; hot partitions (GS + BBG)
  • Consistency models: strong, eventual, causal; CAP, PACELC (DDIA ch.9, GS)
  • Message queues: Kafka vs RabbitMQ vs SQS; at-least-once/exactly-once; idempotency (BBG + HN)
  • Rate limiting: token bucket, leaky bucket, sliding window (Shrayansh Jain LLD)

Deliverable: Implement an LRU cache + token-bucket rate limiter (machine coding) with unit tests

Phase 2 — LLD Core: SOLID + Patterns (Weeks 4-5)

  • SOLID principles with violations + fixes (Refactoring Guru + Shrayansh Jain)
  • Creational: Singleton, Factory, Builder, Prototype (Concept && Coding)
  • Structural: Adapter, Decorator, Facade, Proxy, Composite (Concept && Coding)
  • Behavioral: Strategy, Observer, Command, State, Template Method (Concept && Coding)
  • UML class diagrams: associations, composition vs aggregation, multiplicity (SudoCODE)
  • Schema design: ER diagrams, normalization, indexing strategy for LLD problems

Deliverable: Refactor a "God class" into SOLID-compliant design; draw class diagram before coding
