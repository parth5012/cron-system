Design and develop a software prototype that learns the evolving state of a computer network from traffic telemetry and predicts the likelihood and progression of malicious activity before compromise is completed. The solution should ingest network traffic, learn temporal behaviour, forecast future attack states and provide interpretable decision support for defenders. Solutions should demonstrate applicability to enterprise environments and Critical Information Infrastructure.<br><br> &#8226; Represent network state using feature vectors or graphs.<br> &#8226; Learn state-transition dynamics using sequence models (LSTM, Transformer), Graph Neural Networks, latent state models or other AI techniques.<br> &#8226; Forecast future network states and estimate the probability of attacker progression.<br> &#8226; Map predicted behaviour to recognised attack stages (e.g. MITRE ATT&amp;CK).<br> &#8226; Provide explain ability using attention mechanisms, feature attribution or equivalent ...
