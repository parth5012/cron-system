How it lives in ORCA

• Ocean Data Library (MOSDAC/Bhuvan STAC) → Fast Map Memory (PostGIS ST_AsMVT tiles) → /api/tiles/pfz/{z}/{x}/{y}.pbf
• Smart Combiner ranks PFZ candidates by SST+chlorophyll+wind+tide+safety, adds rank field
• Map renders rank1 cyan (best safe), rank2 slate, hazard red hatch
• Tap zone → Safety Check citation + route polyline + “Send to phone (SMS/Voice)”
