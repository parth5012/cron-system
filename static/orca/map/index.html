How this works

1. INCOIS publishes daily fish advisory (437 spots across 14 states)
2. ORCA extracts, converts to GeoJSON map dots
3. 4 helpers check each dot (fish + sea + wind + danger)
4. Smart Combiner picks best SAFE spot for you
5. Map shows blue (best) / grey (ok) + route + SMS alert
