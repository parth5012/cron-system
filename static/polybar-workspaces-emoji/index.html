Workspace styles — round 3: cute emojis 🎉

Yes — emojis work in your polybar. Verified live on your machine: Symbola is already installed, so emoji render tinted to your theme colors (monochrome outlines), no nerd font needed.
Mock shows: 1st = active  ·  2nd = occupied  ·  rest = empty
One line to enable: add to [bar/main]:
font-1 = "Symbola:size=10;2"  (shift the other font-N up if needed)

Optional full COLOR emoji: run sudo apt install fonts-noto-color-emoji, then add font-2 = "Noto Color Emoji:size=10;2". Note: monochrome Symbola (default) actually matches the Rosé Pine bar better — color emoji can look loud next to muted tones.
