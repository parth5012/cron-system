2. Job Jargons

bearing / depth / distance
232° azimuth, 55-60m depth, 12km distance — INCOIS 7-col table → GeoJSON properties
landing center / harbor / jetty
Where fisherman starts. Kochi, Munambam, Kasimedu etc. → GPS lookup
haversine 80→120→160km
Closest-zone search radius expansion if no safe zone
geofence / ST_DWithin / ST_Contains
Is point inside EEZ/MPA? Within 2km IMBL? PostGIS check
safety badge + DO NOT SAIL
Green <1.5m/<15kt, Yellow 1.5-2.5m, Red >2.5m/>25kt/cyclone/MPA veto
green route / fly-to
Map flies to winner, draws safe route from GPS dot
swell / tide / upwelling / front / bloom
Swell height/period, tide range, SST front, plankton bloom = fish
artisanal / small craft / set sail
