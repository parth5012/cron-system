1️⃣ Hybrid Retrieval (Dense + Sparse)
Never rely on vector similarity alone. Combine:
• Dense embeddings (text-embedding-3-large) for semantic nuance
• Sparse search (BM25 / PostgreSQL full-text search) for exact keywords
• Reciprocal Rank Fusion (RRF) to merge and normalize scores.

Tweet 4/7

2️⃣ Cross-Encoder Reranking
Vector search gives you candidate recall (top 30-50).
Run candidates through a Cross-Encoder (e.g., Cohere Rerank / BGE-Reranker) to extract top 5 precision chunks.

Reranking alone boosts retrieval relevance by 30-40%.

Tweet 5/7

3️⃣ Self-Reflective LangGraph Loop (CRAG)
Structure your retrieval in a cyclic state graph:
1. Retrieve: Fetch candidate chunks
2. Grade Documents: Fast LLM/classifier scores chunk relevance
3. Decision branch:
- If relevant -> Generate Answer
- If irrelevant -> Rewrite Query -> Fallback

Tweet 6/7

4️⃣ FastAPI Async Streaming & pgvector HNSW
• Store embeddings in PostgreSQL with pgvector HNSW indexes for sub-10ms similarity queries.
